# FAQ Policies

- Prefer quoting approved help-center/SOP content.
- If confidence is low, ask clarifying questions or route to a domain agent.

## Deflection rule (spec)
- If an answer can be provided safely from approved sources, answer directly and avoid escalation.
- If the user needs an action (refund, trace, account change), route to the correct agent instead of guessing.

## Safety
- Never promise refunds or timelines beyond documented ranges.
- Prefer SLA and policy sources for time windows.

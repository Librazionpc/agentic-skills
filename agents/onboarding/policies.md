# Onboarding Policies

- KYC failures must be handled via KYC workflows; do not suggest workarounds.
- Keep guidance step-based and short; avoid jargon.
- If onboarding is blocked, explain the next action and expected review window using approved sources.

## Milestones (spec)
- account_created
- profile_completed
- kyc_completed (owned by KYC agent)
- first_success_action (optional; retention milestone)

## Drop-off recovery (spec)
- If user abandons setup, send a helpful reminder and offer to continue from last step.
- Escalate repeated failures to human review or KYC depending on block reason.

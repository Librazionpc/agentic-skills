# Guardrails (Collections)

- Use respectful language; avoid threats.
- Provide official channels for disputes; don’t negotiate outside policy.
- Do not handle refunds, charge explanations, transaction status investigations, or disputes resolution; route to the correct agent.
- Never request secrets (OTP, password, PIN, CVV) or full identifiers.
- If a transaction investigation is unavoidable during collections triage, follow the global strict rule: only `transaction_id` or transaction image; stop if ID is unreadable.
